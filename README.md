# mono2.css

 Minimal design based on black and white.

![;)](https://i-am-youre-engineer.github.io/mono2.css/img/share.png)

## Feature

Mono2.css is a minimal CSS framework. <br>A simple monochrome design can be applied and only a minimum style is prepared so that users can freely expand.

<img src="https://i-am-youre-engineer.github.io/mono2.css/img/logo.png" width="208">

## Installation

Just load CSS

```html
<link rel="stylesheet" href="https://i-am-youre-engineer.github.io/mono2.css/css/mono2.css">
```

## Usage

Just copy and edit HTML.

example:

```html
<header class="header">
  <div class="inner">
    <div class="header-logo">M0N02</div>
    <p>mono2.css is Minimal design based on <span class="marker">black</span> and white.</p>
  </div>
</header>
```

Click [here](https://i-am-youre-engineer.github.io/mono2.css/#document) for details.
