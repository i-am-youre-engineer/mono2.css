Original idea @kokushin.

Feature Usage Document GitHub

Feature

Mono2.css is a minimal CSS framework.
A simple monochrome design can be applied and only a minimum style is prepared so that users can freely expand.

Cloning GitHub, Donwload Zip

Usage

Just load CSS

<link rel="stylesheet" href="https://i-am-youre-engineer.github.io/mono2.css/css/mono2.css">

Document

The components provided in version 1 are as follows:

  • Header
  • Footer
  • Menu
  • Section

  • Code
